# CSE411 Introduction to Compilers

## Setting Up

1. Fork this repository following the instructions given in this [page](https://docs.github.com/en/get-started/quickstart/fork-a-repo#forking-a-repository).
2. Open a command line terminal and clone the forked project in your local machine.
   ```bash
    git clone https://github.com/<your-github-id>/CSE411-2026-Fall.git
   ```
3. You will need the following tools installed on your local machine:
   1. sbt (Scala Build Tool) 2.0.8
   2. Java Development Kit (JDK) 26.0.2.1
4. You can build the project using sbt:
   ```bash
   sbt compile
   ```
